## :dart: O guia para alavancar a sua carreira

> GitHub é a maior plataforma de hospedagem de código e colaboração do mundo: mais de 100 milhões de pessoas desenvolvedoras usam Issues, Pull Requests, Actions, Pages, Projects e Copilot para versionar, revisar, automatizar e publicar software todos os dias. Saber usar bem o GitHub deixou de ser diferencial e virou pré-requisito — é lá que você constrói portfólio, contribui com open source e é avaliado em processos seletivos. Este guia reúne documentação oficial, cursos gratuitos e pagos, livros, canais, ferramentas, projetos práticos e um capítulo dedicado a usar IA (GitHub Copilot e cia.) no seu fluxo de trabalho diário — tudo verificado e organizado para quem já entende o básico de Git e quer dominar a plataforma de ponta a ponta.

## 💡 Nossa proposta

> A proposta deste guia é dar uma ideia sobre o atual panorama e guiá-lo se você estiver confuso sobre qual será o seu próximo aprendizado, sem influenciar você a seguir os 'hypes' e 'trends' do momento. Acreditamos que com um maior conhecimento das diferentes estruturas e soluções disponíveis poderá escolher a ferramenta que melhor se aplica às suas demandas. E lembre-se, 'hypes' e 'trends' nem sempre são as melhores opções.

## 🤖 IA na prática

GitHub é, hoje, também uma plataforma de IA: o **GitHub Copilot** está integrado ao editor, ao Pull Request, às Actions e até a tarefas que rodam sozinhas na nuvem. Veja como aproveitar isso sem virar refém da sugestão errada.

**Para aprender**
- Peça ao [GitHub Copilot Chat](https://docs.github.com/en/copilot/using-github-copilot/copilot-chat) para explicar um workflow de Actions linha a linha, ou para sugerir por que um job está falhando a partir do log colado.
- Use o [GitHub Copilot Chat](https://docs.github.com/en/copilot/using-github-copilot/copilot-chat) direto na página de uma Issue ou Pull Request para resumir uma discussão longa antes de opinar.
- Peça exemplos de `.yml` de workflow comentados linha a linha e depois valide rodando localmente com o [act](https://github.com/nektos/act).

**Para trabalhar**
- O [Copilot coding agent](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/cloud-agent) recebe uma Issue atribuída a ele, abre uma branch, escreve o código e devolve um Pull Request pronto para revisão — sem você tocar no editor.
- O [GitHub Copilot](https://github.com/copilot) revisa Pull Requests automaticamente, sugerindo comentários de code review antes de um humano olhar.
- Use os [GitHub Copilot Extensions](https://github.com/features/copilot/extensions) para conectar o Copilot Chat a ferramentas externas (Docker, Sentry, bancos de dados) sem sair do GitHub.
- O [GitHub MCP Server](https://github.com/github/github-mcp-server) expõe Issues, PRs e Actions do GitHub como ferramentas para agentes de IA via Model Context Protocol — use com Claude Code, VS Code ou qualquer cliente MCP.
- Explore o [GitHub Models](https://github.com/marketplace/models) para testar diferentes modelos de IA direto no Marketplace, sem sair do GitHub.

**Limites e boas práticas**
- Siga as [boas práticas oficiais de uso do Copilot](https://docs.github.com/en/copilot/get-started/best-practices) — a sugestão da IA é ponto de partida, não commit final.
- Revise **todo** Pull Request gerado por um agente de IA como revisaria o de qualquer colega: rode os testes, leia o diff inteiro, confira se ele não inventou uma dependência ou endpoint que não existe.
- Nunca aceite automaticamente uma sugestão que mexe em permissões, segredos (`secrets`) ou workflows de deploy sem entender exatamente o que ela faz.
- Configure exclusões de conteúdo sensível e confira a [política de dados do Copilot](https://docs.github.com/en/copilot) antes de usar em repositórios privados de clientes.

## 🎓 Certificações

Em 2024 o GitHub lançou seu próprio programa oficial de certificações (aplicado via Pearson VUE), consolidando um caminho de carreira reconhecível pelo mercado.
- [GitHub Foundations Certification](https://learn.github.com/certifications/github-foundations) — Certificação oficial de base: Git, GitHub, colaboração e conceitos fundamentais da plataforma.
- [GitHub Actions Certification](https://learn.github.com/certifications/github-actions) — Certificação oficial focada em CI/CD com GitHub Actions.

## 💼 Carreira e vagas

O GitHub é hoje parte do processo seletivo de praticamente qualquer vaga técnica: recrutadores olham seu perfil, seus repositórios fixados e sua consistência de contribuições antes mesmo da entrevista.
- [Gerenciando seu README de perfil](https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-github-profile/customizing-your-profile/managing-your-profile-readme) — Guia oficial para criar o README especial que aparece no topo do seu perfil — seu "cartão de visita" para recrutadores.
- [Stack Overflow Developer Survey 2025](https://survey.stackoverflow.co/2025/) — Pesquisa anual com dados sobre ferramentas, salários e como devs usam GitHub no trabalho.
- [GitHub Stars Program](https://stars.github.com/) — Programa oficial de reconhecimento para pessoas que se destacam ajudando a comunidade no GitHub.
- [Programathor](https://programathor.com.br/) — Vagas de tecnologia no Brasil, com perfis que valorizam portfólio no GitHub.
- [GeekHunter](https://www.geekhunter.com.br/) — Plataforma brasileira onde empresas fazem propostas a devs a partir do perfil técnico.
- [Coodesh](https://coodesh.com/) — Vagas tech no Brasil com processos seletivos padronizados, muitos usando desafios via GitHub.
- [Remotar](https://remotar.com.br/) — Vagas 100% remotas para brasileiros.
- [GitHub Education Pack](https://education.github.com/pack) — Pacote gratuito para estudantes com ferramentas pagas liberadas (inclusive Copilot) — ótimo para começar o portfólio.
- [Tech Interview Handbook](https://www.techinterviewhandbook.org/) — Preparação completa para entrevistas técnicas, incluindo como apresentar projetos do GitHub.
